# Addressables Helper

> Reserved module for future Addressables helper APIs.

## Current status

This repository is currently a placeholder. It does not yet contain runtime
code, an assembly definition or a Unity Package Manager manifest.

Use Unity Addressables directly, or use the existing `ResourceLoader` and
`SceneSwitcher` modules for Addressables-based resource and scene operations.

## Planned scope

This module is reserved for focused helpers around common Addressables workflows
without duplicating the responsibilities of `ResourceLoader` or `SceneSwitcher`.

Until an API is added, there is nothing to install or configure.
